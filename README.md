Rent Pay

A Java EE web application developed as an academic software project.

Overview

Rent Pay is a web-based application designed to support rental-related information management and user interactions.

Technologies Used

- Java EE
- JavaServer Pages (JSP)
- HTML and CSS
- JavaScript
- Database technology used by the project

Main Modules

- User registration and login
- Admin and client interfaces
- Application submission
- Inquiry management
- Search and filtering
- User settings

Only include features that are actually implemented in the project.

Requirements

- Java Development Kit (JDK) compatible with the project
- A compatible Java EE application server
- A database server, if required
- An IDE such as Eclipse or IntelliJ IDEA

Setup

1. Clone this repository.
2. Import the project into your IDE.
3. Configure the application server and database
4. Configure any necessary environment settings.
5. Build and deploy the application.

Project Purpose

This project was developed for academic learning and software development practice.
